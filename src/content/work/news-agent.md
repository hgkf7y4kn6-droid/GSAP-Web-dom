## The problem

Staying current means checking dozens of sources by hand, then trying to remember where you read what.

## What I built

News Agent is a personal news reader that pulls from 62 sources. It includes an AI chat assistant that answers questions about the news and cites the articles behind each answer.

It runs on Cloudflare Workers, with Cloudflare Vectorize for search and Gemini for the chat assistant.

## Where it stands

News Agent is open source. The code is on GitHub.
