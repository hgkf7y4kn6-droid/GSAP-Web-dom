## The problem

Routine patient requests such as refills, record lookups and appointment changes tie up staff, who have to move between several systems to handle each one.

## What I built

AegisTriage is a multi-agent healthcare assistant built as my capstone for the Microsoft Applied Generative AI Specialization. Specialized agents cover four workflows: prescription refills, EHR lookups, scheduling and support tickets.

It's written in Python with CrewAI and exposes a webhook API.

## Where it stands

AegisTriage is a capstone project. The code is on GitHub.
